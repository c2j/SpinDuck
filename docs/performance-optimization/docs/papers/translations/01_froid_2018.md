# Froid: Optimization of Imperative Programs in a Relational Database (PVLDB 2018)

## 中文标题
Froid：关系数据库中命令式程序的优化

## 核心思想摘要
将命令式标量UDF（变量赋值、顺序块、IF-ELSE）自动转化为关系代数表达式并内联进外层SQL，使优化器能够进行基于成本的集合化执行。

## 对 SpinDuck 引擎及集合化架构的启示与映射
在SQL Server中落地为标量UDF内联。启发SpinDuck在编译期将无表依赖的FROM sys_dummy赋值折叠为IR。
