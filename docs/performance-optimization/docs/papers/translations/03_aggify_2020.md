## 中文标题
优化关系数据库中的游标循环（Aggify）

## 核心思想摘要
针对逐行游标循环（RBAR），自动分析循环体内的状态转移与分支依赖，合成为等价的自定义聚合函数（UDAF）或集合查询，将十万级迭代变成单次流水线扫描。

## 对 SpinDuck 引擎及集合化架构的启示与映射
直击prc_trd_deal_purchase等游标主循环痛点，是实现十万行从百秒级跃迁至秒级的理论基石。
